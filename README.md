# Node.js REST API

A backend REST API built with Node.js, Express, and MongoDB.

The project includes user authentication, session management, password recovery via email, and avatar uploads.

## 🛠 Tech Stack

- **Node.js** — JavaScript runtime
- **Express.js** — Backend framework
- **MongoDB & Mongoose** — Database and data modeling
- **JWT** — Token-based authentication
- **bcrypt** — Password hashing
- **Nodemailer** — Sending password reset emails
- **Multer** — File uploads
- **Cloudinary** — Image storage

## 🚀 Features

- User registration and login
- Password hashing
- Authentication and authorization
- Access and refresh token management
- User logout
- Password reset via email
- User avatar uploads
- MongoDB database integration
- RESTful API endpoints
- Request validation and error handling

## 📦 Installation

Clone the repository:

```bash
git clone https://github.com/Roman2846/nodejs-hw.git
```

Install dependencies:

```bash
npm install
```

Create a `.env` file and configure the required environment variables.

Start the development server:

```bash
npm run dev
```
